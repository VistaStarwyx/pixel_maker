# pixel_maker 像素图生成器
A Web page code that converts an image to pixel art.
将图片转换为像素图的网页代码。

**PS:**

Inspired by the pixel module in Arknights' "Fantastic Wonders" exhibition, The required code is mainly generated by Deepseek. (I can't code myself😭)

受到明日方舟奇象巡展中巡展像素模块的启发，主要由Deepseek生成所需代码。

**Instruction:**

Just download the file **index.html** and run it on the browser.

直接下载 **index.html** 并在浏览器运行喵～
