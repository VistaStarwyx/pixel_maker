# pixel_maker
A Web page code that converts an image to pixel art.
将图片转换为像素图的网页代码。

**PS:**

Inspired by the pixel module in Arknights' "Fantastic Wonders" exhibition.

受到明日方舟奇象巡展中巡展像素模块的启发。

**Instruction:**

Just download the file **pixel_maker.html** and run it on the browser.

直接下载**pixel_maker.html**并在浏览器运行即可喵～
